# 🚀 YOLO-World: Open-Vocabulary Object Detection Using Text Prompts

Explore **YOLO-World**, an open-vocabulary object detection model that detects objects using custom text prompts without retraining the model.

In this project, we use Python, Ultralytics, and YOLO-World to detect objects in images by simply changing text prompts.

## 🎥 YouTube Tutorial

Watch the complete tutorial:

[YOLO-World: Detect Any Object Using Text Prompts](https://youtu.be/OvnhAFx9_wM)

## ✨ Features

- Detect objects using custom text prompts.
- Detect black cars, people with white shirts, bags, and bicycles.
- Detect multiple object categories simultaneously.
- Visualize bounding boxes, labels, and confidence scores.

## ⚙️ Technologies Used

- Python
- YOLO-World
- Ultralytics
- OpenCV
- Matplotlib
- PyTorch
- Google Colab
